## Project structure

```
.
├── app.py              # Streamlit app
├── config.py           # paths, target column, split settings
├── evaluation.py       # metric computation
├── train.py            # trains models, saves them, writes test_data.csv
├── requirements.txt
├── test_data.csv       # held-out test split (generated by train.py)
├── data/dataset.csv    # full raw dataset
└── model/              # saved .joblib pipelines
```

## Setup and usage

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 1. put the dataset at data/dataset.csv and set TARGET_COL in config.py
# 2. train, save models and generate test_data.csv
python train.py

# 3. run the app
streamlit run app.py
```
